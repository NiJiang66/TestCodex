# Lua 简化麻将游戏

这是一个使用 **Lua** 编写的命令行麻将演示项目，目标是展示清晰的模块化结构，便于扩展规则（如吃碰杠、番型计分等）。

## 项目结构

- `main.lua`：程序入口。
- `src/tile.lua`：麻将牌模型与基础工具。
- `src/wall.lua`：牌墙构建与洗牌/摸牌逻辑。
- `src/player.lua`：玩家行为（摸牌、打牌、AI 或人类输入）。
- `src/rules.lua`：胡牌判定（当前为 4 面子 + 1 对将的基础判定）与简单弃牌建议。
- `src/game.lua`：对局流程控制（发牌、轮转、结束判断）。

## 运行方式

```bash
lua main.lua
```

## 当前实现说明

- 使用万/条/饼三种花色，每种 1-9 共 108 张牌。
- 4 名玩家（1 名人类 + 3 名机器人）。
- 支持：发牌、摸牌、打牌、自摸胡牌判定、流局判定。
- 未实现：吃、碰、杠、点炮、番型计分。

## 扩展建议

1. 在 `rules.lua` 中新增番型识别与得分模块。
2. 在 `game.lua` 中加入他家响应流程（吃碰杠胡优先级）。
3. 增加测试脚本，对关键牌型进行回归验证。
